# DocAsk - AI Document Question Answering System

## 🌐 Live Demo

Website URL: https://docask-ai.netlify.app/

---

## 📌 Overview

DocAsk is an AI-powered document question-answering application that allows users to upload documents and interact with them using natural language questions. The system extracts information from uploaded files, processes the content, and uses AI to provide answers based on the document context.

The application supports multiple document formats including PDF, DOCX, TXT, PNG, JPG, and JPEG. For image-based documents, OCR technology is used to extract readable text before processing.

---

## ✨ Features

- 📄 Upload documents in multiple formats:
  - PDF
  - DOCX
  - TXT
  - PNG
  - JPG
  - JPEG

- 🔍 Intelligent document processing:
  - Text extraction
  - OCR-based image text recognition
  - Text cleaning
  - Document chunking
  - Relevant information retrieval

- 🤖 AI-powered question answering using Gemini

- ⚡ Fast API-based backend architecture

- 🛡️ Error handling for:
  - Unsupported files
  - Corrupted documents
  - Empty content
  - Processing failures
  - AI service errors
